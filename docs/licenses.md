# QR機能で使用するライブラリ

MameInOut本体はMITライセンスです。QRの表示と読み取りには、次のライブラリを使用しています。

| ライブラリ | バージョン | ライセンス |
| --- | --- | --- |
| [qrcode](https://github.com/soldair/node-qrcode) | 1.5.4 | [MIT](../apps/web/public/licenses/qrcode-LICENSE.txt) |
| [jsQR](https://github.com/cozmo/jsQR) | 1.4.0 | [Apache License 2.0](../apps/web/public/licenses/jsqr-LICENSE.txt) |

稼働中のサイトでも `/licenses/NOTICE.txt`、`/licenses/qrcode-LICENSE.txt`、`/licenses/jsqr-LICENSE.txt` から確認できます。その他の依存ライブラリについては、それぞれの配布物に含まれるライセンスが適用されます。

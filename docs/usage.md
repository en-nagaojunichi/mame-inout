# 管理者とQR受付の操作

現在は開発中です。管理者や受付端末を登録できますが、QRを読み取る受付画面、名簿、在室一覧、履歴の操作画面は準備中です。新機能は検証中のため、運用前に使う端末とブラウザで確認し、登録する情報は動作確認用にしてください。

## 管理者の画面と、QR受付に使う端末

**管理者の設定**は、管理者が自分のスマートフォンやPCでパスキーを使ってログインし、管理者の追加や受付端末の承認などを行う画面です。名簿や記録を管理する機能も、管理者向けに提供します。

**QR受付に使う端末**は、入口などに置き、利用者のQRコードを読み取って入退出を記録するスマートフォン・タブレットです。受付用に承認されたブラウザで使い、日常のQR読み取りでは管理者のログインやパスキー認証は不要です。受付用の資格で名簿や管理者の設定は操作できません。

登録の流れは「受付に使う端末で申請 → 管理者が自分の設定画面で承認 → 申請した端末で利用開始」です。受付に使う端末にも、管理者と同じサイトを開いてください。共有の受付端末へ、管理者個人のパスキーを登録する必要はありません。

## 最初の管理者を登録する

1. AndroidではChrome、iPhoneではSafariを起動し、サーバー管理者から案内されたHTTPSのURLをアドレス欄へ貼り付けて開きます。証明書の警告が出ないことを確認してください。
2. 「最初の管理者を登録」が表示されたら、サーバー管理者から受け取った設定コード、表示名、メールアドレスを入力します。設定コードの有効期限は発行から15分です。
3. 「パスキーを登録」を押し、端末の指紋・顔認証・画面ロックなどの案内に従います。
4. 登録後に表示される復旧コードを、端末とは別の安全な場所へ保存します。コードはこの画面で一度だけ表示されます。
5. 「保存したので閉じる」を押し、「接続を確認できました」と表示されていることを確認します。

パスキーは管理者が個人で使う端末に登録してください。共有の受付スマートフォンに管理者のパスキーを追加する運用は避けてください。

メールアドレスは管理者を識別するために使います。確認メールは送信されず、画面にも「未確認」と表示されます。本番で使うURLを確定してから登録してください。ドメインが変わると、同じパスキーをそのまま使えない場合があります。

復旧コードの発行だけに失敗した場合は、パスキーの再登録は不要です。ログイン後に「管理者の設定」から復旧コードを発行してください。

## ログインとログアウト

登録したときと同じURLを開き、「パスキーでログイン」を押します。登録済みのパスキーを選び、端末の案内に従ってください。「接続を確認できました」と表示されたらログイン完了です。

操作を終えるときは「ログアウト」を押し、ログイン画面に戻ったことを確認します。30分間操作しなかった場合、またはログインから12時間が経過した場合も、再度ログインが必要です。

パスキーの変更、管理者の招待・停止、復旧コードの発行、受付端末の承認・失効では、対象と影響を確認して実行します。ログインなどでパスキーの本人確認をしてから5分以内は、その確認を利用します。時間が過ぎている場合は「本人確認して承認」などのボタンから再確認します。認証をキャンセルした場合、その変更は行われません。

## パスキーを追加・変更・失効する

ログイン後に「管理者の設定」を押します。「パスキー」には名前、登録日、最終利用が表示されます。

- **追加する**：「パスキーを追加」から名前を入力し、本人確認の後、新しく使うパスキーを登録します。
- **名前を変更する**：対象の「名前を変更」を押します。端末や保存先を見分けられる名前にしてください。
- **使えなくする**：対象の「失効」を押し、対象と影響を確認します。そのパスキーでログインしたセッションも使えなくなります。

紛失したパスキーを失効するときは、先に別のパスキーでログインできることを確認してください。最後のパスキーは失効できません。

## 別の管理者を招待する

1. 設定画面の「管理者を招待」を押し、招待する本人の表示名とメールアドレスを入力します。
2. パスキーで本人確認した後、表示された招待コードを控えます。コードは一度だけ表示され、15分間有効です。
3. サイトのURLと招待コードを、招待した本人だけに安全な方法で伝えます。コードをURLの末尾に付けたり、公開の掲示板へ載せたりしないでください。
4. 招待された方は、自分の端末でサイトを開き、「招待された管理者の登録」からコードを入力してパスキーを登録します。別の管理者でログイン中の場合は、先にログアウトしてください。
5. 登録後に表示される復旧コードを保存します。

招待コードは登録が完了すると再利用できません。管理者の停止は、設定画面の対象者にある「管理者を停止」から行います。停止した管理者は、使用中のログイン状態を含めて使えなくなります。最後の有効な管理者は停止できません。

## 管理者の名前を変更する

1. 管理者としてログインし、「管理者の設定」を開きます。
2. 「管理者」の一覧で、対象者の「名前を変更」を押します。自分の名前も変更できます。
3. モーダルに表示された現在の名前を書き換え、「保存」を押します。名前は1〜100文字で入力してください。

表示名だけを変更します。メールアドレス、権限、パスキー、ログイン状態はそのままです。名前だけの変更に追加のパスキー認証はありません。キャンセルした場合は変更せず、通信に失敗した場合は入力した名前を保持して案内します。

## 復旧コードを保管・再発行する

復旧コードは、パスキーを使えなくなったときに本人のログインを復旧するためのものです。初回登録・招待からの登録・復旧後に表示されたコードは、安全な場所に保存してください。各コードは1回だけ使えます。

設定画面の「復旧コードを発行」または「復旧コードを再発行」から、新しいコードを発行できます。再発行すると、それまでの復旧コードはすべて使えなくなります。閉じた後に同じコードを再表示することはできません。保存し忘れた場合は、再発行して新しいコードを保存します。

## パスキーを使えなくなった場合

1. ログイン画面の「パスキーを使えない場合」を開きます。ログイン中の場合は、先にログアウトしてください。
2. 登録済みのメールアドレスと、未使用の復旧コードを1つ入力します。
3. 新しく使うパスキーを登録します。復旧の開始から5分以内に登録を完了してください。
4. 新しい復旧コードを保存し、設定画面を開けることを確認します。

復旧コードは、復旧を開始した時点で使用済みになります。パスキー登録をキャンセルした場合も、同じ画面を開いたまま、開始から5分以内であれば、進行中の登録手続きから再試行できます。画面の再読込、別のコードでの開始、有効期限切れの後は、別の未使用コードでやり直してください。復旧を完了するまでは、以前のパスキーとログイン状態が保持されます。復旧中の許可だけで管理操作はできません。

新しいパスキーの登録が完了すると、以前のパスキー、すべてのログイン状態、以前の復旧コードは無効になります。新しく登録したパスキーと、保存した新しい復旧コードを使用してください。

復旧コードもすべて失った場合は、次のサーバー管理者向けの手順で復旧します。

## サーバー管理者が復旧コードを発行する

この操作は、設置先のサーバーを管理する方が対話端末で行います。対象の管理者本人を確認してから実行してください。

Composeファイルのあるディレクトリで、次を実行します。`admin@example.test`は登録済みの管理者メールアドレスに置き換えてください。実際の起動に追加のComposeファイルを使っている場合は、同じ組合せを指定します。

```sh
docker compose exec api node dist/admin-recovery-code.js admin@example.test /tmp/new-recovery-code
```

コードはAPIコンテナ内の指定ファイルへ保存されます。既存ファイルは上書きされません。同じ保存先が残っている場合は、別の新しいファイル名を指定してください。非対話実行では発行できません。

ファイルの内容は、第三者に見えず、出力を記録しない手元の対話端末で確認します。公開ログ、チャット、画面共有へコードを載せないでください。コードは対象の管理者本人へ安全に渡し、前の節の復旧画面で使用します。復旧が完了したら、保存したコードのファイルを削除してください。

発行すると、その管理者の以前の復旧コードと、進行中の復旧は無効になります。以前のパスキーとログイン状態は、新しいパスキーで復旧が完了するまで保持されます。

## QR受付に使う端末を登録する

管理者用のログインと受付端末の登録は別です。管理者がログインしただけでは受付端末になりません。

1. 受付で実際に使うスマートフォンのブラウザで、管理者と同じサイトの「QR受付に使う端末を登録」を開きます。管理者のログインは不要です。
2. 見分けやすい端末名を入力し、「管理者へ承認を申請」を押します。
3. 表示された端末名と8桁の確認コードを管理者に見せます。申請の期限は10分です。
4. 管理者は自分の端末で「管理者の設定」を開き、「QR受付に使う端末」の一覧を更新します。対象端末の「承認」を押し、実際の受付に使う端末と確認コードが一致することを確認します。
5. 有効期間を1〜90日で指定して承認します。初期値は30日です。直近の本人確認から5分を過ぎている場合は、パスキーで再確認します。
6. 受付端末側の「承認の状態を確認」を押します。承認済みになったら、「このブラウザで利用を開始」を押します。
7. 「このブラウザで登録済みです」と有効期限が表示されていることを確認します。

資格を受け取れるのは申請したブラウザだけです。確認コードを別のブラウザに入力して登録することはできません。申請から10分を過ぎる前に、承認と「このブラウザで利用を開始」まで完了してください。登録後は、申請の10分が過ぎても管理者が指定した有効期限まで使えます。

受付端末を紛失した場合は、管理者の設定画面で対象端末を失効してください。過去の記録は保持され、その端末は次の受付操作から拒否されます。期限切れ、拒否、失効、ブラウザの登録情報を消した場合は、管理者に確認して新しく申請します。

## QR受付に使う端末の名前を変更する

管理者として「管理者の設定」を開き、「QR受付に使う端末」の対象にある「名前を変更」を押します。現在の端末名を書き換え、モーダルの「保存」を押してください。名前は1〜100文字で入力します。

端末名だけの変更なので、再申請や再承認は不要です。登録・承認状態、有効期限、過去の入退出記録は保持します。申請中や停止した端末も名前を変更できますが、名前を変えても利用可能な状態にはなりません。受付画面の名前は、状態の再確認や再読み込みで更新されます。

## 操作を完了できないとき

- **「対応ブラウザ」の案内が出る**：AndroidはChrome、iPhoneはSafariのアプリを直接起動し、同じURLをアドレス欄へ貼り付けてください。LINEなどのアプリ内でページを表示している場合も、この手順で開き直します。
- **設定コード・招待コードが使えない**：入力内容と有効期限を確認してください。初期設定済みの設定コードや、登録済みの招待コードは使えません。
- **端末の認証をキャンセルした**：操作は完了していません。画面からもう一度試してください。復旧の登録中は、同じ画面を開いたまま、開始から5分以内であれば、その登録手続きから再試行できます。画面の再読込、別のコードによる開始、期限切れの後は、別の未使用の復旧コードを使ってください。
- **通信が途切れた・結果が分からない**：「状態を再確認」や「登録の状態を再確認」で確認します。受付端末の資格受取で応答が失われた場合は、申請した同じブラウザから、申請期限内にもう一度利用開始を試せます。
- **招待・復旧の登録結果が分からない**：画面で登録済みと確認できた場合は、設定画面を開いて復旧コードの発行状態を確認してください。パスキーの再登録は不要です。確認できない場合は、同じ画面の有効な登録手続きから再試行するか、ログイン画面で新しいパスキーを選んで確認してください。
- **復旧コードの発行結果が分からない**：再表示はできません。パスキーでログインできる場合は設定画面で再発行し、新しいコードを保存してください。
- **「操作が続いています」と表示される**：繰り返し押さず、画面で案内された時間を待ってから試してください。

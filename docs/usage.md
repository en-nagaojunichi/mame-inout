# 管理者の登録とログイン

現在は開発中の認証確認版です。入退出の受付、名簿、在室一覧、履歴はまだ利用できません。登録する情報は動作確認用にしてください。

## 最初の管理者を登録する

1. AndroidではChrome、iPhoneではSafariを起動し、サーバー管理者から案内されたHTTPSのURLをアドレス欄へ貼り付けて開きます。証明書の警告が出ないことを確認してください。
2. 「最初の管理者を登録」が表示されたら、サーバー管理者から受け取った設定コード、表示名、メールアドレスを入力します。設定コードの有効期限は発行から15分です。
3. 「パスキーを登録」を押し、端末の指紋・顔認証・画面ロックなどの案内に従います。
4. 「接続を確認できました」と表示されたら、登録が完了しています。

メールアドレスは管理者を識別するために使います。確認メールは送信されません。現在は最初の管理者と1つのパスキーを登録できます。管理者の招待、パスキーの追加、紛失時の復旧はまだ利用できません。

## ログインとログアウト

登録したときと同じURLを開き、「パスキーでログイン」を押します。登録済みのパスキーを選び、端末の案内に従ってください。「接続を確認できました」と表示されたらログイン完了です。

操作を終えるときは「ログアウト」を押します。ログイン画面に戻ったことを確認してください。ログインから30分が経過した場合も、再度ログインが必要です。

## 操作を完了できないとき

- **「対応ブラウザ」の案内が出る**：AndroidはChrome、iPhoneはSafariのアプリを直接起動し、同じURLをアドレス欄へ貼り付けてください。LINEなどのアプリ内でページを表示している場合も、この手順で開き直します。
- **設定コードが使えない**：入力内容を確認し、期限切れの場合はサーバー管理者に再発行を依頼してください。初期登録が完了している場合、設定コードは使えません。
- **端末の認証をキャンセルした**：操作は完了していません。画面からもう一度試してください。
- **通信が途切れた・結果が分からない**：「状態を再確認」を押し、表示された状態に従ってください。
- **パスキーが見つからない**：登録した端末やパスキーの保存先を確認してください。現在は紛失時の復旧ができないため、サーバー管理者に相談してください。

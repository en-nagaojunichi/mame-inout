| 再生位置の目安 | 内容 |
| --- | --- |

| 00:25 | 管理者の端末と、QRを読む受付端末の役割を説明します。管理者が記録を確認するイメージ映像も紹介します。 |

操作画面は専用の架空データを使い、実際の画面・API・PostgreSQLを通して収録しています。パスキーには自動検査用の仮想認証器、カメラにはテスト用の映像を使用しています。読み取りに使うQR画像と初期設定・復旧コードは映していません。スマホ実機の撮影映像ではありません。

冒頭の入口・管理者の映像は、利用場面を伝える生成映像です。「利用場面のイメージ」と表示しています。実施設での導入実績、実利用者の記録、製品画面の動作を示すものではありません。

利用想定の図は、架空の場面を描いた説明用イラストです。[利用想定の図を見る](../images/use-cases.png)と、どのような場所で使うかを確認できます。

## 試す前に

日付が変わっても自動退室しません。QRの貸し借りや退室忘れにより、記録上の在室者と実際に滞在している人が異なる場合があります。通信できない状態では、受付を確定できません。扉の解錠は行いません。

現在は正式リリース前です。動画に映った操作だけで本番運用の受入が完了したことにはなりません。[確認済みの範囲と未確認の項目](../overview.md#確認できている範囲)を確認してください。

自分で試すときは、[架空の1人で行うテスト受付](../usage.md#はじめてのテスト受付)へ進んでください。設置には[導入手順](../install.md)、日常の操作には[画面の使い方](../usage.md)があります。
